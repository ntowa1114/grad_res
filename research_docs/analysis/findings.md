# 判明したことと、主張の根拠の対応

実験結果から判明したこと、卒論で主張できる範囲（候補）、根拠を整理する。
出典の略称は `README.md` を参照。実験の詳細は `../experiment_index.md`。
「主張候補」は資料から読み取れる範囲での整理であり、研究者の決定ではない。最終的な主張は研究者が決める。

## 2. 卒論で主張できること（候補）と根拠の対応

| 主張候補 | 根拠 | 強さ | 不足している裏付け |
|---|---|---|---|
| (a) MV3 拡張の案A/案Bは、平文送信の場合、別オリジン iframe 内からのカード送信を L1〜L3 まで観測できる | F1, F2（[P]） | PoC の範囲で実測 | 他の方式、送信手段、反復、実環境（eTLD+1・証明書） |
| (b) 案Aの成否は、content script の world と注入範囲（`all_frames`）に依存する | F2, F3（[P]）、F10（[H]） | MAIN true は実測。ISOLATED は実測だが条件の詳細が不明。`all_frames=false` は予測 | 本実験では追加の測定をしない（D42） |
| (c) 宛先の照合（PoC では PSP 宛だけを許可）だけでは、正規と悪性を一意に分離できない | F6（[P 実験4]） | 正規側の1ケースのみ実測 | 悪性（スキマー検体）を使った L4 の測定 |
| (d) MV3 では、Bower のブロック方式（body 照合による request の cancel）は成立しない | [H §10]（外部仕様） | 一次資料がリポジトリにない | Chrome 公式ドキュメントでの確認 |
| (e) 観測可能性は決済方式によって異なる | F18〜F20（本実験の18条件）。**この条件では、方式による差は出なかった**（ブラウザを通る送信は全て L1〜L4 とも ○。ブラウザを通らない外縁③は別扱い） | 5型・案A・案B・各3回で実測。ただし自作EC・平文・`fetch` のみ | 符号化・XHR・実在の PSP の JS など、差が出得る条件の測定（【仮説】）。主張は「この条件で差が出なかった」までで、「方式によらない」とは言えない |
| (f) 難読化・符号化で観測がどう変わるか | 現時点の根拠なし | 未検証 | 符号化するスキマーの検体と L3 復元の実験（本実験では行わない。D30、`experiment_spec.md` §10） |
| (g) 日本の EC における決済方式・実態 | 現時点の根拠なし | 調査を行わない（D45）。主張しない | — |

【解釈】PoC の範囲（(a)(b)(c)）に加え、本実験の測定（F18〜F20）で、自作EC・平文・`fetch` のみの条件では、案A・案Bとも、ブラウザを通る送信を L1〜L4 まで観測できた。研究の軸である「どこで失明するか」の境界は、この条件では出ていない（外縁③を除く）。差が出得る条件（(f) の符号化など）は未測定。

## 3. 研究上の限界（資料に記載されたもの）

- 別オリジンはホスト名とポートの差で再現しており、eTLD+1 の差や証明書は扱っていない。（[P]）
- 「L3○」は平文送信に限る。難読化時は未検証。（[P]）
- PoC は単発の成否のみ。反復・到達率は未実施。（[P]）
- PoC は送信手段が fetch のみ。方式が2つのみ。（[P]）
- PoC は正解記録がサーバー受信ログのみ。（[P]）
- 観測の範囲外: ブラウザを通らない外縁（サーバー側スキミング）。（[H §5]）
- 本実験の「全欄 ○」は、自作EC・自作スキマー・`fetch` のみ・平文・正規宛先を設定として渡す（D51）・各3回の結果。L3 の復元ルール（13〜19桁の数字の取り出し）と L4 の判定（正規宛先との一致）は、実装者の選択（`product/NOTES_assumptions.md` #46）で、ルールを変えれば結果が変わり得る。
