# 判明したことと、主張の根拠の対応

実験結果から判明したこと、卒論で主張できる範囲（候補）、根拠を整理する。
出典の略称は `README.md` を参照。実験の詳細は `../experiment_index.md`。
「主張候補」は資料から読み取れる範囲での整理であり、研究者の決定ではない。最終的な主張は研究者が決める。

## 2. 卒論で主張できること（候補）と根拠の対応

| 主張候補 | 根拠 | 強さ | 不足している裏付け |
|---|---|---|---|
| (a) MV3 拡張の案A/案Bは、平文送信の場合、別オリジン iframe 内からのカード送信を L1〜L3 まで観測できる | F1, F2（[P]） | PoC の範囲で実測 | 他の方式、送信手段、反復、実環境（eTLD+1・証明書） |
| (b) 案Aの成否は、content script の world と注入範囲（`all_frames`）に依存する | F2, F3（[P]）、F10（[H]） | MAIN true は実測。ISOLATED は実測だが条件の詳細が不明。`all_frames=false` は予測 | `all_frames=false` の実測 |
| (c) 宛先の allowlist だけでは、正規と悪性を一意に分離できない | F6（[P 実験4]） | 正規側の1ケースのみ実測 | 悪性（スキマー検体）を使った L4 の測定 |
| (d) MV3 では、Bower のブロック方式（body 照合による request の cancel）は成立しない | [H §10]（外部仕様） | 一次資料がリポジトリにない | Chrome 公式ドキュメントでの確認 |
| (e) 観測可能性は決済方式によって異なる | 現時点の根拠なし | PoC は2方式で、両方 ○ | 5型の実装と測定（2026-10-24 に4分類から5型へ変更。`../research_decisions.md` C6） |
| (f) 難読化・符号化で観測がどう変わるか | 現時点の根拠なし | 未検証 | 軸3の検体と L3 復元の実験 |
| (g) 日本の EC における決済方式・実態 | 現時点の根拠なし | 未着手 | 実態調査 |

【解釈】現時点の実測だけで言えるのは (a)(b)(c) の PoC 範囲まで。研究の軸である「どこで失明するか」を示す根拠（(e)(f)）は、検体と本測定が済んでいない。

## 3. 研究上の限界（資料に記載されたもの）

- 別オリジンはホスト名とポートの差で再現しており、eTLD+1 の差や証明書は扱っていない。（[P]）
- 「L3○」は平文送信に限る。難読化時は未検証。（[P]）
- 単発の成否のみ。反復・到達率は未実施。（[P]）
- 送信手段が fetch のみ。方式が2つのみ。（[P]）
- 正解記録がサーバー受信ログのみ。（[P]）
- 観測の範囲外: ブラウザを通らない外縁（サーバー側スキミング）。（[H §5]）
