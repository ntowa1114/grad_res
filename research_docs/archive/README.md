# archive/（過去の記録。現行ではありません）

**ここにあるファイルは、現行の決定や現状を表しません。** 作業前に読む必要はありません。
研究の現状と決定は、`research_docs/` 直下のファイルと `research_docs/experiment_spec.md` を見てください。

## 目的

- 方針変更の経緯（旧→新）を失わないために残す。卒論の「方針変更の経緯」、口頭試問での経緯の説明に使う。
- 現行ファイルを、決定と現状だけにするために、旧版と経緯をここに分けた。

## 中身

| 場所 | 内容 |
|---|---|
| `2026-11-02_再構成前/` | 再構成を始める前（2026-11-02）の `research_docs/` の主要ファイルの全文コピー。変更・要約はしていない |
| `decisions_history.md` | 方針変更の経緯（C1〜C12）、変更された旧い決定、解消した論点（旧Q）、用語の変更 |
| `open_issues_resolved.md` | 解消した未解決事項（E-1、E-10、U-9、U-14、U-18）と解消の経緯 |
| `原本との差分.md` | 原本（[H]、[S] など）の古い記述と、現行の決定の対応 |

## 読むときの注意

- コピーには、後に変更された決定（旧4型、3軸OFAT、`allowlist` など）がそのまま書かれている。現行の決定と食い違うのは、そのためである。
- `literature/` は再構成で変更しないため、コピーを置いていない。
- 原本（リポジトリ直下の資料）は変更・移動していない。
